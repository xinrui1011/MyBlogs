大家好，今天的blog我想来分享一下我用AI写出了一个个人网站的过程

## 第一步——告诉AI我的核心目的

我是这样对AI描述的“**我现在需要做一个个人网站，网站页面风格需要达到国际化且富有科技感，整体主题颜色为蓝色，网站第一个界面为我的个人简介，个人简介内容：身份为在读大学生，最近正在学习AI，做这个网站的目的是记录自己学习AI的过程，喜欢尝试新事物。个人简介之后另起一个新界面兴趣爱好，爱好旅游，追剧，看书，这里可以添加相对应的图片。**”

告诉它我需要的基本信息以及视觉要求，几分钟后个人网站初见雏形。

## 第二步——对我的个人网站进行加工
AI直接生产的网站有以下几点不全
- 网站背景过于单调
- 底部邮箱地址错误
- 网站功能不全
1. 我在React Bits ——一个开源的 UI 组件集合里找到了我需要的背景动画，将它提供的代码复制给AI并且告诉它“**我需要把这段代码生成的动画效果应用到我的个人网站的背景上**”背景单调的问题解决了
2. “**网站底部的邮箱需要替换我自己的邮箱xxx.com**”告诉他它即可
3. 我想要能上传我的个人作品，example：大学学习笔记、旅游攻略、大学生活分享，我只需要告诉他“**我现在要添加一个展示个人作品的界面，但是我现在没有素材，你先构建一个界面给我，让我可以随时添加作品**”现在我就拥有了一个能上传我的个人作品的界面。

## 第三步——调试网站上传作品的功能
### 现在我们要来检查它有没有什么bug

第一篇blog是我让AI生成的一篇教会大家如何用markdown写作的格式，大家可以移步我的**第一篇blog**在短暂的学习之后我开始了我的第二篇blog于是问题出现了**我的第二篇blog写完上传后并没有同步到我的网站**我一直强制刷新我的网站试图解决问题，很显然，并没有什么用。于是我将求助的目光移到了AI身上”**我点开我的第二篇博客，并没有内容**“我告诉了它我现在遇到了一个什么样的bug，把情况一五一十地告诉它。几分钟我再刷新页面，我的文章能在我的blog上看到了！

## 第四步——将我的个人网站上传到github
- 首先我们需要在GitHub 上新建仓库
```markdown
打开 https://github.com
 并登录你的账号
点右上角 + → New repository
填写：
Repository name：比如 my-website（或你喜欢的名字）
选择 Public（公开）或 Private（私有，仅自己可见）
⚠️ 不要勾选 "Add a README" / ".gitignore" / "license"（避免和本地冲突）
点 Create repository
```
- 然后将建好的仓库地址发给AI
- 其次HTTPS 认证（推送时需要）
```markdown
推送时 GitHub 需要身份验证（没有 gh CLI / SSH key，用 HTTPS + Token）：
GitHub 网页 → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
勾选 repo 权限，生成后复制那串 ghp_... 开头的 token
推送时：
Username 填你的 GitHub 用户名
Password 填那串 token（不是登录密码）
```
在github上获取*Username*和*Password*发给AI
- 最后用 GitHub Pages 直接上线网站
```markdown
GitHub 仓库页面 → Settings → Pages
Source 选 Deploy from a branch → 分支 main → 目录 / (root) → Save
等 1-2 分钟，你的网站就能通过网址访问
```
## 第五步——复制网址去浏览器打开检查是否有bug
⚠️因为在本地和在github page上不一定同步，而我则出现了这样的bug

**我在本地可以看到我的blog内容，当我复制网址打开后我的blog显示为空**
我告诉AI“**我的本地可以看的我的blog，但是在github page上无法看到我上传的blog，请你帮我查找并解决这个bug**”很快我的网站就恢复了正常
