大家好，我是这个网站的作者 👋

这是我的第一篇博客。做这个网站的目的是记录我学习 AI 的过程，而记录的第一步，就是先学会 **Markdown** —— 一种用纯文本写文章的格式。写博客、写 README、写笔记都用得上它，简单又优雅。

这篇笔记会把 Markdown 的常用语法都过一遍，顺便作为本站文章的「语法参考手册」，以后写新文章时可以随时回来看。

## 1. 标题

Markdown 用 `#` 表示标题，`#` 越多，级别越小：

```markdown
# 一级标题（就是这里用的 `##` 的上一级）
## 二级标题
### 三级标题
#### 四级标题
```

注意：标题前后最好留一个空行，`#` 后面记得加一个空格。

## 2. 文字样式

这是**加粗**、这是*斜体*、这是***加粗加斜***、这是~~删除线~~，这是 `行内代码`。

```markdown
**加粗**  用两个星号
*斜体*    用一个星号
***粗斜体***  用三个星号
~~删除线~~    用两个波浪号
`行内代码`    用反引号包起来
```

## 5. 代码块

代码块用三个反引号包裹，后面可以注明语言，页面会自动高亮：

```python
# Python 示例：我的 AI 学习计划
plan = ["Python 基础", "机器学习", "深度学习", "大模型应用"]
for i, item in enumerate(plan, 1):
    print(f"第 {i} 步：{item}")
```

```javascript
// JavaScript 示例
const goal = "记录 AI 学习过程";
console.log(`我的目标：${goal}`);
```

```bash
# 终端示例
mkdir ai-learning
cd ai-learning
git init
```

如果想在文章里展示「代码块本身」的写法（就像这篇笔记一样），用**四个反引号**包裹三层反引号：

````markdown
```python
print("这是一段被展示出来的代码块语法")
```
````

## 6. 表格

| 语法 | 作用 | 难度 |
| ---- | ---- | :--: |
| `#` 标题 | 组织文章结构 | ⭐ |
| `**加粗**` | 强调重点 | ⭐ |
| 列表 | 罗列内容 | ⭐⭐ |
| 代码块 | 展示代码 | ⭐⭐ |
| 表格 | 对比信息 | ⭐⭐⭐ |

```markdown
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 内容 | 内容 | 内容 |
```

第二行是分隔线：`---` 表示默认左对齐，`:---:` 居中，`---:` 右对齐。

## 7. 链接

- 普通链接：[Markdown 官方教程](https://www.markdownguide.org/)
- 带标题的链接（鼠标悬停可见）：[GitHub](https://github.com "全球最大代码托管平台")

```markdown
[链接文字](https://链接地址)
[带提示的链接](https://链接地址 "悬停提示")
```

## 8. 图片

- 网络图片：`![图片说明](https://图片地址)`
- 本地图片：把图片放进 `articles/images/`，然后写 `![图片说明](./images/图片名.png)`

语法和链接几乎一样，只是前面多一个 `!`：

```markdown
![图片说明](图片地址)
```

## 9. 水平线

三个以上的 `-`、`*` 或 `_` 都能画一条分割线：

---

```markdown
---

* * *

___
```

## 10. 转义与 Emoji

有些符号是 Markdown 的语法标记，想原样输出时，前面加反斜杠 `\` 转义：

```markdown
\*这个星号不会被当作斜体\*

\# 这个井号不会变成标题
```

Emoji 可以直接写在正文里，很多 Markdown 编辑器还能自动联想：🚀✨🎓📝
